# Релевантные исходные материалы

Этот список фиксирует только файлы, необходимые на текущем этапе. Полные каталоги `step_files` и `stl_files` в анализ не включались.

| Материал | Роль в проекте | Вывод для ближайшего этапа |
|---|---|---|
| `KiCad/Pickit.sch` | Демонстрационная схема KiCad старого формата | Подходит для выбора реальных УГО и связей компонентов |
| `KiCad/Pickit.kicad_pcb` | Демонстрационная печатная плата KiCad | Подходит для выбора footprint и привязок компонентов |
| `KiCad/Pickit_Bom.csv` | Спецификация компонентов Pickit | Удобна для выбора небольшой тестовой выборки |
| `FreePCB/detector/detector.cds` | Проект Схематора FreePCB2 | Подходит для проверки импорта и представления схемы |
| `FreePCB/detector/det.fpc` | Проект ПлатФорм FreePCB2 | Подходит для проверки импорта и представления платы |
| `ProjectFreeCad-master/step_stl_conversion_checked.py` | Проверочный конвертер STEP → STL на Gmsh | Готовый отдельный контур; полный повторный запуск сейчас не нужен |
| `FreePCB.pdf`, `FreePCB_Lib.pdf` | Документация FreePCB | Подтверждает формат `.fpl`: он повторяет секцию `[footprints]` файла проекта |
| `stl_files` | Готовые STL-результаты | Не изучается на текущем этапе; использовать позднее для привязки 3D-моделей |
| `step_files` | Справочная база STEP | Не изучается на текущем этапе |

## Важное разграничение

Файлы `Pickit.sch`, `Pickit.kicad_pcb`, `detector.cds` и `det.fpc` — файлы проектов плат. Они не заменяют библиотечные исходники и не задают формат конвертера библиотек напрямую. Их роль — выбрать реалистичные компоненты для сквозной демонстрации после появления правил преобразования библиотек.

## Рекомендуемая тестовая выборка

1. `R2` с footprint `R_0805_HandSoldering` как простой пассивный компонент.
2. `P1` типа `CONN_01X06` как многоконтактный разъём.
3. `U3` типа `PIC24FJ256GB106` как многовыводная микросхема.

Такая выборка проверит основные случаи без массового обхода файлов.

## Первый результат

Создан `output/R_0805_2012Metric.fpl` из одного KiCad footprint. Конвертер расположен в `src/kicad_to_freepcb_footprint.py`; он покрывает площадки, линии и прямоугольники шелкографии. Формат генерации уточнён по сохранённому эталонному проекту `Эталон R_0805_2012Metric/R_0805_2012Metric.fpc`: нанометры, числовые коды площадок, обязательные поля текста и синтаксис полилиний. Следующая проверка — импорт обновлённого `.fpl` в ПлатФорм.
