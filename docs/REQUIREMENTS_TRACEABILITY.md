# Матрица требований и подтверждений

| ID | Требование | Подтверждение | Текущий статус |
|---|---|---|---|
| R-01 | Читать библиотеки KiCad | Тест на эталонных `.kicad_sym` и `.kicad_mod` | В проекте есть демонстрационный `.sch` и `.kicad_pcb`, библиотечные образцы ещё нужны |
| R-02 | Преобразовывать УГО | Импорт результата в Схематор и визуальное сравнение | Требуется формат FreePCB2 |
| R-03 | Преобразовывать footprint | Импорт результата в ПлатФорм и визуальное сравнение | Реализован первый `.kicad_mod` → `.fpl` для простых площадок и шелкографии; требуется импортная проверка |
| R-04 | Переносить метаданные компонентов | Сравнение атрибутов исходного и целевого объекта | Требуются правила соответствия |
| R-05 | Вести журнал ошибок и предупреждений | Отчёт по тестовой партии | Не начато |
| R-06 | Поддерживать пакетную конвертацию | Повторяемый запуск на тестовой библиотеке | Не начато |
| R-07 | Конвертировать STEP в STL | Контроль геометрии и файлового результата | Реализован отдельным проверочным скриптом, повторный прогон не требуется сейчас |
| R-08 | Сохранять структуру каталогов 3D-библиотек | Сравнение относительных путей до и после | Отложено по текущей договорённости |
| R-09 | Привязывать 3D-модели к компонентам | Отображение модели в ПлатФорм | Требуется описание ссылок |
| R-10 | Повторно запускаться без ручной настройки | Два запуска с одинаковым результатом | Не начато |

## Блокирующие входные данные

Для начала реализации необходимы:

1. Минимум по одному эталонному библиотечному компоненту в KiCad и FreePCB2 для УГО и footprint. Доступные сейчас файлы — проекты плат, а не библиотечные образцы.
2. Версии целевых приложений и описание форматов либо исходный код их импорта.
3. Правила именования и разрешения коллизий.
4. Решение о том, как учитывать 7 000 уже обработанных 3D-моделей в итоговой метрике.
