# Матрица требований и подтверждений

| ID | Требование | Подтверждение | Текущий статус |
|---|---|---|---|
| R-01 | Читать библиотеки KiCad | Тест на эталонных `.kicad_sym` и `.kicad_mod` | Parser `.kicad_mod` и четыре библиотечных fixtures есть; parser symbols и полный набор libraries ещё нужны |
| R-02 | Преобразовывать УГО | Импорт результата в Схематор и визуальное сравнение | Требуется формат FreePCB2 |
| R-03 | Преобразовывать footprint | Импорт результата в ПлатФорм и визуальное сравнение | SMD/PTH/NPTH, тексты, слои, apertures, контуры и ограниченная аппроксимация реализованы; четыре примера проверяются автоматически; Windows/GUI/Gerber ещё не проверены |
| R-04 | Переносить метаданные компонентов | Сравнение атрибутов исходного и целевого объекта | Требуются правила соответствия |
| R-05 | Вести журнал ошибок и предупреждений | Отчёт по тестовой партии | JSON-отчёт одного footprint и strict rejection есть; журнал партии пока не реализован |
| R-06 | Поддерживать пакетную конвертацию | Повторяемый запуск на тестовой библиотеке | Не начато |
| R-07 | Конвертировать STEP в STL | Контроль геометрии и файлового результата | Ранее получены 7 225 STL, есть исторические скрипты; модели повторно не конвертируются; геометрия на текущем этапе не проверялась |
| R-08 | Сохранять структуру каталогов 3D-библиотек | Сравнение относительных путей до и после | Matcher сохраняет категорию `.3dshapes` в отчёте, исходные каталоги не меняет; переносимый целевой комплект ещё нужен |
| R-09 | Привязывать 3D-модели к компонентам | Отображение модели в ПлатФорм | Сопоставление существующего STL и `openscad_code` реализованы по исходникам 2.428; физическое совмещение и Windows-экспорт не проверены |
| R-10 | Повторно запускаться без ручной настройки | Два запуска с одинаковым результатом | Четыре единичных `.fpl` воспроизводимы, старые CLI/API сохранены; batch/resume пока нет |

## Недостающие данные и проверки

Разработка footprint-конвертера уже идёт; отсутствие Windows её не останавливает.
Для следующих этапов необходимы:

1. Реальная библиотека УГО Схематора и компонент с подтверждённой связью УГО → footprint; целевой формат не восстанавливать по догадке.
2. Load/save roundtrip полученных `.fpl` в FreePCB2 **2.428**, Gerber/NPTH и физическая проверка 3D. Контракт `.fpl` уже изучен по исходникам зафиксированной ревизии.
3. Полные версии исходных KiCad libraries, правила именования, коллизий и pin mapping для связей компонентов и batch.
4. Отдельный учёт ранее полученных 7 225 STL: факт существования не означает подтверждённую связь/трансформацию каждого footprint. Новая работа использует существующие файлы.

Практический порядок продолжения: [PROJECT_PLAN.md](PROJECT_PLAN.md).
