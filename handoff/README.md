# Комплект для Windows-приёмки

Этот каталог содержит всё необходимое для контрольной проверки поддержанного
профиля конвертера на Windows:

| Файл | Размер | SHA256 |
|---|---:|---|
| `native-validation-kit.zip` | 1 908 153 байта | `eaa9ae83aa24381f0538e8c7cf6f0765ec7fbc10dee654cdae56ec7b898a8012` |
| `linked-smoke.zip` | 110 787 байт | `95e1ee09ab52e1471ff8c7f6ca6b915f7606a29b5242d3613bc6c9463fb7772a` |

Скачать оба файла после клонирования репозитория, проверить хеши, распаковать
целиком и следовать [порядку Windows-проверки](../docs/WINDOWS_HANDOFF.md).
Основной архив включает `protocol.json`, `expected-catalog.json`, автономный
`verify_kit.py` и место для `results/`. Второй архив содержит три реальные
связанные пары CDS/FPL из массовой поставки, нужные STL, лицензии исходных
библиотек и автономный `verify.py`.

Полная preview-поставка из 8 210 связанных компонентов занимает 307 265 987
байт в ZIP и не хранится в Git: GitHub ограничивает размер одного обычного
Git-объекта. Для десяти сценариев native-приёмки достаточно этих двух архивов;
результаты и любые обнаруженные различия нужно вернуть вместе с `results/run.json`.
